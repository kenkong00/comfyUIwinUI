# AI 角色生成器 - 项目架构文档

## 📋 项目概述

基于 Vue 3 + Vite + Express + SQLite 的 AI 角色生成与对话平台，支持多用户、本地数据库存储、ComfyUI 图片生成集成。

**当前版本**: v3.0 (本地数据库版)

---

## 🏗️ 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | Vue 3 (Composition API) | SPA 单页应用 |
| **构建工具** | Vite 6.x | 开发/构建 |
| **状态管理** | Pinia 3.x | 全局状态管理 |
| **后端服务** | Express 4.x | API 服务器 |
| **本地数据库** | SQLite (better-sqlite3) | 持久化存储 |
| **认证方案** | JWT (jsonwebtoken) + bcryptjs | 用户认证 |
| **图片下载** | Express 静态服务 | ComfyUI 图片保存 |

## 🗄️ 数据库设计

### ER 关系图

```
users (用户)
  ├── id (PK, UUID)
  ├── username, email, password_hash
  └── 1:N → user_configs, characters, conversations, generated_images, sessions

user_configs (用户配置)
  ├── id (PK), user_id (FK→users)
  ├── config_type: global_settings | ai_providers | workflow_templates | ui_layout
  └── config_data (JSON)

characters (角色)
  ├── id (PK), user_id (FK→users)
  ├── name, description, avatar_url, system_prompt
  ├── personality, background_story, preferred_model
  ├── model_parameters, generation_workflow, image_settings
  └── is_favorite, is_archived

conversations (对话历史)
  ├── id (PK), user_id (FK→users), character_id (FK→characters)
  ├── title, messages (JSON array)
  ├── message_count, token_count_estimate
  └── is_pinned, is_bookmarked

generated_images (生成的图片)
  ├── id (PK), user_id (FK→users)
  ├── character_id (FK→characters), conversation_id (FK→conversations)
  ├── image_url, prompt, negative_prompt
  ├── workflow_used, model_used, width, height
  └── format, file_size

sessions (登录会话)
  ├── id (PK), user_id (FK→users)
  ├── token (JWT, UNIQUE)
  └── created_at, expires_at
```

### 核心原则：**多租户隔离**

- 所有业务表通过 `user_id` 外键关联用户
- `ON DELETE CASCADE` — 删除用户时自动清理所有关联数据
- 所有 API 接口强制校验 `user_id`，确保数据隔离

## 🔐 认证流程

```
注册: POST /api/auth/register { username, email, password }
  → bcrypt.hash(password) → 写入 users 表 → 生成 JWT → 返回 token + user

登录: POST /api/auth/login { username/email, password }
  → 查询 users → bcrypt.compare → 生成 JWT → 写入 sessions → 返回 token

验证: GET /api/auth/verify (Header: Bearer <token>)
  → JWT.decode → 查 sessions 表确认有效 → 返回 user 信息

登出: POST /api/auth/logout (Header: Bearer <token>)
  → 删除 sessions 记录 → 清除前端 localStorage
```

**JWT 配置**:
- Secret: `ai-character-platform-local-secret-2024`
- 有效期: 7 天
- Payload: `{ userId, username }`

## 🛠️ API 端点总览

### 认证（无需 Token）
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/register` | 注册新用户 |
| POST | `/api/auth/login` | 登录获取 JWT |
| POST | `/api/auth/verify` | 验证 Token 有效性 |
| POST | `/api/auth/logout` | 登出 |

### 用户信息（需 Token）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/user/me` | 获取当前用户信息 |
| PUT | `/api/user/profile` | 更新用户资料 |

### 角色管理（需 Token）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/characters` | 获取我的所有角色 |
| GET | `/api/characters/:id` | 获取单个角色详情 |
| POST | `/api/characters` | 创建角色 |
| PUT | `/api/characters/:id` | 更新角色 |
| DELETE | `/api/characters/:id` | 删除角色 |
| POST | `/api/characters/import` | 批量导入角色 |
| GET | `/api/characters/export/all` | 导出全部角色 |

### 配置管理（需 Token）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/configs` | 获取所有配置 |
| GET | `/api/configs?type=xxx` | 获取指定类型配置 |
| POST | `/api/configs` | 保存/更新配置 |

### 对话管理（需 Token）

## 🔄 数据同步策略

```
┌─────────────┐     自动保存(1s防抖)     ┌─────────────┐
│   前端 UI   │ ──────────────────────→  │  Local DB   │
│  (Pinia)    │ ←──────────────────────  │  (SQLite)   │
└─────────────┘     登录时加载           └─────────────┘
        ↓                                    ↓
   localStorage (降级备份)              data.db 文件
```

**同步规则**:
1. **已登录 + API 可用** → 通过 HTTP 保存到 SQLite
2. **API 不可用 / 未登录** → 降级到 localStorage
3. **编辑操作** → 1 秒防抖后自动同步
4. **网络恢复** → 自动触发全量同步
