# AI聊天性能优化指南

## 📊 性能基准

### 正常响应时间范围
- ✅ **优秀**: < 5秒
- ✅ **良好**: 5-10秒
- ⚠️ **一般**: 10-20秒
- ❌ **慢**: 20-30秒
- 🔴 **异常**: > 30秒

## 🔍 性能诊断

### 查看控制台日志
打开浏览器控制台（F12），你会看到详细的性能分析：

```
🚀 开始AI请求: {provider: "aliyun", url: "...", model: "qwen-plus"}
⏱️ 首字节响应耗时: 3.25秒
✅ 收到响应: 200 OK
⏱️ 首块数据耗时: 0.15秒
📊 性能分析:
  - 总耗时: 75.32秒
  - 网络请求: 3.25秒
  - 流式传输: 72.07秒
```

### 性能瓶颈识别

#### 1. 网络请求慢（首字节 > 5秒）
**原因:**
- DNS解析慢
- 网络延迟高
- API服务器响应慢
- 代理配置问题

**解决方案:**
- 切换到国内服务商（硅基流动、阿里云）
- 检查网络连接
- 使用CDN加速
- 优化代理配置

#### 2. 流式传输慢（传输时间 > 30秒）
**原因:**
- AI生成长文本
- 模型推理慢
- 网络带宽限制
- 请求参数不合理

**解决方案:**
- 减少max_tokens限制
- 使用更快的模型
- 优化提示词长度
- 减少对话历史长度

## 🚀 优化建议

### 1. 选择合适的服务商

| 服务商 | 平均响应 | 稳定性 | 推荐场景 |
|--------|----------|--------|----------|
| 硅基流动 | 3-8秒 | ⭐⭐⭐⭐⭐ | 国内首选 |
| 阿里云百炼 | 5-15秒 | ⭐⭐⭐⭐ | 企业应用 |
| OpenAI | 5-12秒 | ⭐⭐⭐⭐⭐ | 需要代理 |
| OpenRouter | 8-20秒 | ⭐⭐⭐ | 多模型选择 |

### 2. 优化模型选择

**快速响应模型:**
- Qwen2.5-7B-Instruct（推荐）
- GPT-4o-mini
- DeepSeek-V2.5

**高质量模型:**
- Qwen2.5-72B-Instruct
- GPT-4o
- Claude-3.5-Sonnet

### 3. 减少对话历史

在设置中添加对话历史限制：
```javascript
// 建议只保留最近10-20条消息
const recentMessages = messages.slice(-20)
```

### 4. 优化提示词

- 保持系统提示简洁
- 避免重复内容
- 使用结构化格式

### 5. 网络优化

**检查网络连接:**
```bash
# 测试DNS解析
nslookup dashscope.aliyuncs.com

# 测试网络延迟
ping dashscope.aliyuncs.com

# 测试下载速度
curl -o /dev/null -s -w "Time: %{time_total}s\n" https://dashscope.aliyuncs.com
```

**优化代理配置:**
- 使用HTTP/2
- 启用压缩
- 增加超时时间

## 🛠️ 故障排查

### 问题1: 响应时间 > 60秒

**检查清单:**
- [ ] 网络连接是否正常
- [ ] API密钥是否有效
- [ ] 服务商是否在线
- [ ] 是否达到配额限制
- [ ] 模型是否正确

**解决步骤:**
1. 测试网络连接
2. 切换服务商
3. 检查API配额
4. 联系服务商支持

### 问题2: 首字节响应慢

**可能原因:**
- DNS解析慢 → 使用公共DNS（114.114.114.114）
- 网络延迟高 → 使用CDN或代理
- 服务器负载高 → 切换服务商

### 问题3: 流式传输慢

**可能原因:**
- 生成内容过长 → 限制max_tokens
- 模型推理慢 → 使用更快的模型
- 网络带宽限制 → 检查网络质量
